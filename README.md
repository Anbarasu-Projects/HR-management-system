# AttendEase HR Management System

AttendEase is a web-based Human Resource Management System designed to help organisations manage employees, attendance, leave, payroll, departments, shifts and other HR-related activities from a central platform.

The application provides separate HR/admin and employee functionality and was developed using Next.js, TypeScript and MongoDB.

## Features
The system includes:

- Employee registration and management
- Admin approval for employee registration
- Employee login and authentication
- Attendance tracking
- Clock-in and clock-out
- Work session tracking
- Department management
- Shift management
- Leave application and approval
- Half-day leave support
- Medical leave support
- Leave balance management
- Payroll management
- Payslip generation
- Employee birthday notifications
- HR/Admin dashboard
- Employee dashboard
- Password management
- Email notifications
- Audit and activity tracking
- HR reports
